# Governance

These files make the repository's current authority, responsibility, benefit, and ethical boundaries inspectable. They implement decisions for this public, manuscript-only project; they do not create authority over Indigenous, community-governed, personal, restricted, or sensitive ecological data.

| File | Purpose |
| --- | --- |
| `BENEFIT.md` | Intended beneficiaries, observable benefit, burdens, and the option not to automate |
| `policy.json` | Machine-readable action permissions, compute boundaries, model rules, approval gates, and logging policy |
| `RESPONSIBILITY.md` | Named human ownership, consequential workflows, review gates, and correction routes |
| `harm-register.json` | Project-specific unacceptable outcomes, prevention, detection, escalation, recovery, and owners |
| `INCIDENT_RESPONSE.md` | Lightweight response and correction procedure |
| `AI_DISCLOSURE.md` | Disclosure and validation expectations for material AI assistance |

The default is deny or stop when an action, data class, service, model, or authority is not listed. Change these policies only through review by the responsible human in `project.json`. When affected people or legitimate rights-holders have authority, their decisions supersede repository-maintainer preferences.
