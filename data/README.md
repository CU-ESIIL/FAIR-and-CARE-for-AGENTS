# Data

This repository distributes no research dataset and approves no governed or sensitive data for use by agents, CI, external models, or public logs. The manuscript, public metadata, and citation records are repository content, not an environmental research dataset.

Before any dataset is added or referenced, document its title, steward, source, stable identifier and exact version, access method, checksum where feasible, format and schema, units, coordinate reference system, missing-value conventions, license, required citation, allowed purposes and actions, approved compute and models, retention, disclosure limits, responsible human, legitimate authority, and deletion or return obligations.

Do not commit large or externally governed data by default. Prefer an immutable identifier and authorized streaming or lazy-access procedure when appropriate. Access never implies permission to copy, infer, train, combine, publish, or redistribute. Unknown rights or permissions require the workflow to stop.
