# Results

`results/reproduction/` is the documented destination for the locally reproduced current manuscript PDF, Ecology formatting proof, Supporting Information PDF, citation-audit reports, and run manifest. These are derived outputs; edit the canonical manuscript, supplement, and submission-metadata sources in `manuscript/` and regenerate.

Generated reproduction outputs are ignored by Git by default to avoid confusing a local check with an authorized release. The reviewed PDF at `manuscript/fair_care_agentic_science_v2.pdf` is the current reading copy. Publication or replacement of a public artifact requires the human gate in `governance/policy.json`.
