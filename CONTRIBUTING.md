# Contributing

Contributions are welcome through a GitHub issue or pull request. Before editing, read `README.md`, `AGENTS.md`, and the relevant file in `docs/principles/`.

## Contribution workflow

1. State the goal, instructions, test, and required record before consequential work.
2. Work in editable, portable source formats and preserve canonical paths.
3. Add or update the smallest relevant test.
4. Record material decisions, citations, prompts, and provenance at the level required by `AGENTS.md`.
5. Run `python3 scripts/repository_audit.py`, the manuscript tests, and any affected website checks.
6. Open a pull request. Publication, releases, licensing, scientific claim approval, and changes to governance boundaries require approval from the responsible human named in `project.json`.

Use GitHub issues to challenge an evaluation criterion, report an error, request a correction, or raise a governance concern. Do not put private, governed, security-sensitive, or precise ecological-location information in a public issue.
